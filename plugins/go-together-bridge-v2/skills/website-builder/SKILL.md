description: Plan, design and help build mobile-friendly websites, landing pages, shops and portfolios with authorized development and publishing tools.
---

Inspect the existing website/repository/deployment first when supplied. Define audience, pages, mobile navigation, content and acceptance checks from the request. Use actual content; avoid fake testimonials, products or capability claims. Check available Sites, GitHub, Cloudflare or another authorized builder and load its required skill before using it. Deliver functional pages, responsive styling, accessible controls and error/empty states. Keep product UX focused on visitors. Verify navigation and forms at desktop and narrow viewport widths. Publishing requires the requested destination and scope; report a live deployment only after destination readback. If no build tool exists, provide reviewable source or design and explain that deployment remains pending. Do not embed external Custom GPTs by assuming an API exists.

Read [shared rules](../../references/shared-rules.md) before acting. Check the current host's actual tools, connections and authorization; a skill cannot grant tool access. Distinguish instructions from implemented tools and runtime evidence.
